4.jpg  -> 第二章：走过足迹（一起散步、吹风、看风景的街景或风景照）
5.jpg  -> 第二章：可爱抓拍（珊珊最可爱、搞怪或灿烂笑容的抓拍照片）
6.jpg  -> 第二章：甜蜜合影（两人最有爱、最甜蜜的情侣合照）
7.jpg  -> 第三章：重新牵手（2026.01.18 复合纪念物 / 重新牵手时的照片）
8.jpg  -> 第三章：陪伴守护（互相陪伴打气、日常温暖点滴记录）
